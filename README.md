# Asst2_CubicCurve_Win

Download all files in "starter code" folder

Create a new empty project, add all source files and resource files (objects and shaders), add the property sheet (OpenGL and NanoGUI), make sure you can build and run the starter code (see the cubes, ground plane, coordinate system, and straightlines)

Either modify Curve and Renderer class (.cpp & .h files) to draw the cubic curve.
